Latent Liking Estimation

Author

Tom van Hogen

Introduction

The goal of the provided scripts, which contents are the same as the code within this document, is to estimate a participant’s latent liking scores, based on the behavioral data collected during the MRI experiment. These scores provide perhaps the most up-to-date representation of aesthetic liking, and could most closely track the neural activity in the brain in relation to this factor.

The behavioral data collected from the MRI experiment resulted from a continuous 1-back task, where the subject is asked to give a preference of one out of two paintings, i.e., the currently presented painting, or the previous one. This can be viewed as a logistic regression problem, which estimates the probability of one painting being chosen over the other one. Going further, we can supply each painting with a latent score, and translate the probability to a distance between each painting’s latent score, where a high probability of painting X being picked over Y translates to a greater distance in their respective latent scores. This idea comes from the Bradley-Terry model and is outlined in greater detail in the manuscript.

In order to facilitate this model, and to get a good estimate of the estimation uncertainty, we made use of JAGS, which stands for Just Another Gibbs Sampler. In essence, we are applying Bayesian Logistic Regression, but with the Bradley-Terry model underlying it. For more information on the JAGS package, see: https://mcmc-jags.sourceforge.io/.

The code performs the following steps:

  1. Preprocessing the data in order to create appropriate input data for the JAGS model, and to prepare datasets for later analysis.

  2. Setting up the JAGS model and specifying its structure, as well as providing the Markov chains with initial values.

  3. Running the JAGS model to estimate each subject’s latent liking scores for all paintings.

  4. Running analysis on the predictive validity of the model. Here we check how well the latent liking scores predict the final ranking of paintings, which results from a ranking task done after the MRI session.

  5. K-fold validation. In order to check model performance and how well it generalizes, we train the model on one part of the subject’s data and test it against another part (which is unseen data). This is a lengthy procedure as we need to train and test a model k (default = 10)times for each of the 44 subjects.

  6. FInally, we gather all results, run additional analysis and plot everything in order to get a nice view of the model’s performance and ability to predict the final ranking data.

We can now use these imported datasets to start building a data structure that we can use as input data for the JAGS model.

The individual datasets are transformed to two types of matrices: M_pref and M_n. Each matrix has 36 rows and 36 columns, corresponding with the 36 paintings. Each cell represents a pair of paintings which are considered together during a trial of the 1-back MRI task. Cell values represent the amount of preferences for a specific painting in a pair (in the case of M_pref), or the total number of pairings (in the case of M_n). For example, if the cell belonging to painting 5 (row) and painting 13 (column) has the value 3, it means that painting 5 was preferred 3 times over painting 13 (in the case of M_pref), or that the pairing has occurred 3 times in total (in the case of M_n).

2 JAGS Set-Up and Initialization

Before we can run the JAGS model, we need to set up important parameters, specify the model structure, specify the number of Markov chains, and initialize parameter values for the Markov chains.

#### JAGS MODEL ####
modelString <- "
       model{
        sf <- 10 # scale factor
        
        for(i in 1:nPaintings){
          for(j in 1:nPaintings){
            # Likelihood
            y[i,j] ~ dbin(theta[i,j], n[i,j])
            logit(theta[i,j]) <- liking[i] - liking[j]
          }
        }
        # priors
        # Uninformative priors for all paintings except the first.
        for (k in 2:nPaintings){
          liking[k] <- liking_[k] * sf # scaled score
          liking_[k] ~ dbeta(a[k], b[k])
          a[k] <- ifelse((mu[k] * kappa) < 1, 1, mu[k] * kappa)
          b[k] <- ifelse((kappa - a[k]) < 1, 1, kappa - a[k])
          
          # Priors over reparameterizations
          mu[k] ~ dbeta(1,1)
        }
        liking[1] <- sf/2 # fix one value in middle of scale to make model identifiable
        # Hyperprior over kappa
        kappa ~ dunif(0.001, 100) # We assume similar confidence for all comparisons
      }"

# Write model to local textfile
writeLines(modelString, con = "models/ranking_logregres_bin_reparam.txt")

#### JAGS Initialization ####
# Set seed

4 Model Performance Check

4.1 Predictive Validity

Having run the model for each subject, and having an estimation of their latent liking scores for the paintings, we would like to know how well it can predict the results from the final ranking task.

In order to do this, we take the posterior samples (JAGS output) of the latent liking scores from each subject, rank-transform them, and apply a Spearman correlation test together with the final ranking data. In this way, we end up with a posterior distribution of the correlation between latent liking scores and the final ranking data, which is an indication of the predictive validity.

We do some set-up and initialization. Also creating folders if they do not already exist.

# initialize variables
subs_validity <- list() # contains per subject information on the pred. val. posterior distribution.

n_samples <- jags_output_subs$`sub-e01`$sample * nChains
cor_samples_df <- data.frame("sub-e01"=rep(NA, n_samples)) # will contain correlations across model samples
liking_stages_mat <- matrix(NA, 
                           nrow = n_subjects*36,
                           ncol = 5) # Contains liking scores from all three stages

# Create folder for data and figure storage
results_dir <- file.path("..", "results")
ifelse(!dir.exists(results_dir),
       dir.create(results_dir),
       "Directory Exists")

ifelse(!dir.exists(file.path(results_dir, "figures")),
       dir.create(file.path(results_dir, "figures")),
       "Directory Exists")
[1] "Directory Exists"

Then, we iterate over each subject and correlate each posterior sample of the latent liking scores with the final ranking data. We also store a subject’s results in a dataframe containing an overview of the liking scores across all stages of the experiment session, and write this to an excel file called liking_three_stages.xlsx. Furthermore, we store information regarding the predictive validity posterior distribution in a variable called HDI_data, which is stored and labeled by subject in subs_validity.

# Loop across subjects
for (i in 1:n_subjects){
  # string object for picking subject
  subject_string <- subject_dirs_rel[i]
  # Extract MCMC samples for latent ranks
  liking_samples <- combine.mcmc(jags_output_subs[[subject_string]])
  # Calculate correlation for each MCMC sample with the ranking task data. This is a measure of predictive validity.
  cor_samples <- apply(liking_samples, 1, 
                       function(x) cor(rank(-x),
                       true_ranks_subs[[subject_string]]$data$Ranking, 
                       method='spearman')
                       ) # Reverse rank (higher liking scores correspond to higher ranks. In other words, they are closer to rank 1)
  
  # start and end indices depends on subject number
  i_start <- (i-1)*36 + 1
  i_end <- i_start + 35
  # Enter subject number and painting ID
  liking_stages_mat[i_start:i_end, 1] <- subject_string
  liking_stages_mat[i_start:i_end, 2] <- 1:36
  # Extract and store ratings
  subject_rating <- ratings[[subject_string]]$liking_scores
  liking_stages_mat[i_start:i_end, 3] <- subject_rating
  # Extract latent liking scores and store
  subject_latent <- as.numeric(jags_output_subs[[subject_string]]$summary$statistics[,'Mean'])
  liking_stages_mat[i_start:i_end, 4] <- subject_latent
  # Extract rankings and store
  subject_ranking <- true_ranks_subs[[subject_string]]$data$Ranking
  liking_stages_mat[i_start:i_end, 5] <- subject_ranking
  
  # Create csv file with data on subject
  subject_df <- data.frame(
    label = 1:36,
    rating = subject_rating,
    latent_liking = subject_latent,
    ranking = subject_ranking
  )
  
  save_liking_path <- file.path(results_dir, subject_string, "liking_three_stages.xlsx")
  
  # Create directory if necessary
  ifelse(!dir.exists(file.path(results_dir, subject_string)),
         dir.create(file.path(results_dir, subject_string)),
         "Directory Exists")
  # Write csv file
  write_xlsx(subject_df, path=save_liking_path)
  
  # Store in dataframe
  cor_samples_df[subject_string] <- cor_samples
  
  # Summarize the posterior distribution of the correlations
  # First get median values
  median_r <- median(cor_samples)
  # Get highest density interval
  HDI <- hdi(cor_samples)
  # store into list
  HDI_data <- list(median=median_r,
                   HDI.L=as.numeric(HDI)[2],
                   HDI.H=as.numeric(HDI)[3])
  
  
  # Store data to list variable
  subs_validity[[subject_string]] <- HDI_data
}

4.2 k-Fold Validation

In order to check model performance and how well it generalizes, we train the model on one part of the subject’s data and test it against another part (which is unseen data). This is a lengthy procedure as we need to train and test a model k (default = 10)times for each of the 44 subjects.

We start with setting up important parameters. The variable acc_mat is a matrix that will store prediction accuracy values across subjects and folds. It has three columns: subject label, fold number, and prediction accuracy.

# Set parameters
# Model parameters
pars <- c("liking")
nChains <- 3
samples <- 10000
burnin <- 1000
nAdapt <- 1000

# k-fold validation parameters
k <- 10 # number of folds

# Matrix that will store the model prediction accuracy across subjects and folds.
acc_mat <- matrix(NA, nrow=length(datasets)*k, ncol = 3)

Next, we run the k-fold validation procedure. This is a very lengthy process which can easily take up a couple of hours. Make sure to take that into account before running. If you have run it before, there is an option to load the previous results. We will load it here.

# Set parameter to load previous results, or run k-fold validation procedure
load_k_fold <- TRUE

if (load_k_fold==TRUE){
  load(file.path("varstore", "k_fold_val_df.RData"))

  for (S_i in 1:length(datasets)){
    # Get subject data
    subject_string <- subject_dirs_rel[S_i]
    sub_all_data <- datasets[[subject_string]]
    
    for (fold in 1:k){
      # Create train and test datasets
      data <- k_fold_dataloader(sub_all_data, fold, k)
      trainset <- data$train_data
      testset <- data$test_data
      # Prepare matrices for JAGS
      mats <- create_matrices(trainset)
      M_pref <- mats$M_pref
      M_n <- mats$M_n
      # Initialize chains
      set.seed(1234)
      inits <- generate_initial_values(3)
      # Train JAGS model
      # Prepare the data
      dataList <- list(y = M_pref,
                       n = M_n,
                       nPaintings = 36)
      
      # Print message to console
      cat(paste("Running fold", fold, "for", subject_string, "\n\n"))
      # Run JAGS
      output <- run.jags(model="models/ranking_logregres_bin_reparam.txt",
                         monitor=pars,
                         data=dataList,
                         n.chains = nChains,
                         inits=inits,
                         burnin=burnin,
                         sample=samples,
                         adapt=nAdapt,
                         silent.jags = TRUE,
                         method="rjparallel"
      )
      # Use JAGS model to predict
      # Get liking scores
      latent_liking <- as.numeric(output$summary$statistics[,'Mean'])
      # then predict
      preds_df <- predict_response(testset, latent_liking) # Get predictions
      # Evaluate and store results
      conf_mat <- confusionMatrix(preds_df$pred, preds_df$preferredStim) # Get accuracy and related measures
      mat_index_start <- S_i * k - (k-1)
      mat_index_current <- mat_index_start + (fold-1)
      acc_mat[mat_index_current,] <- c(subject_string,
                                       fold,
                                       as.numeric(conf_mat$overall["Accuracy"]))
      
    }
  }
}
